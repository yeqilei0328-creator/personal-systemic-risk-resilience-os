# ADR-0005: Public Method, Private Operational State

Status: Accepted

Decision: 公开仓库保存方法、schema、算法、审计规则与 synthetic examples；真实 Personal Exposure、Capability、Finance、Site、Communications 等 operational state 必须与公开仓库物理分离并存放于私有数据层。

Rationale: 风险/韧性系统本身不应因为“记录得很完整”而降低现实安全边界。

Principle: Open methodology, private exposure.
