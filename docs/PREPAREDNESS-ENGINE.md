# Preparedness Engine — Draft 0.2

## Mission

不是末日购物清单，而是把风险转化为“增加什么、减少什么、等待什么、何时转换”。

## Core metrics

### Lead Time
风险从当前状态到实质影响大约还有多久。

### Preparation Window
某项能力还来得及建设多久。

### Disposition Window
某项资产还可以在合理成本下退出/降杠杆多久。

### Readiness Gap
风险演化速度与准备速度之间的差距。

### Base Autonomy Days
外部支持下降时，基地关键能力可持续天数；以第一失效点为真实自治上限。

### Dual-Use Conversion Value
和平时期创造经济价值、危机时期可转换为生存/韧性能力的程度。

### Conversion Graph
资产可转换成哪些能力、转换时间、依赖条件与持续时间。

## Preparedness domains

- Cash Flow：企业和家庭持续现金流，而非单纯“现金”。
- Liquidity / Financial Assets
- Real Estate & Asset Disposition
- Enterprise / Project Exposure
- Energy / Solar / Storage
- Water / Well / Purification / Storage
- Space / Industrial Buildings / Land
- Food Resilience
- Mobility / Vehicles
- Physical AI / Security / Sensing
- Communications / Offline Network
- Medical / First Aid
- Sanitation
- Tools / Repair / Spares
- Data / Documents / Offline Knowledge
- People / Skills / Trusted Network

## Core principle

长期准备看后果与不可替代性，不必等待高概率；短期高成本行动必须等待更强证据。
