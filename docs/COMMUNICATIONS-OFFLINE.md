# Communications & Offline Compute — Draft 0.2

## Principle

Internet Down ≠ System Down.

关键系统采用 Cloud Enhanced / Local Survivable：云端增强，本地生存。

## Internal network

目标：公网失效后，局域网、摄像头、Physical AI、无人机、本地数据库、能源/水务监控继续运行。

## External communications

采用冗余梯队，不押注单一路径：
- 固网；
- 多运营商蜂窝；
- 经实际合法性/可用性核验的远程/卫星通信；
- 本地无线通信；
- 极端情况下的物理信息传递。

## Offline knowledge base

至少覆盖：地图、医疗急救、设备维修、车辆、光伏储能、水务、农业、食品保存、基地设施图、联系人、应急 Playbooks、Physical AI 软件/模型、核心风险系统规则。

## Graceful degradation target

外部服务逐步失效时，关键能力应分级下降而非归零。
