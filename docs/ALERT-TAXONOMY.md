# Alert Taxonomy — Draft 0.2

不同等级体系禁止混用。

## P0 / P1 / P2 — Intelligence Priority

表示新闻/情报是否值得立即进入模型与打扰用户，不表示全球或个人风险等级。

- P0：必须知道；可能改变模型状态、Lead Time 或行动。
- P1：重要趋势；需要进入模型累积证据。
- P2：背景信息；默认不主动打扰。

## Stage I–IV — Global Systemic Stage

表示全球系统风险的结构状态。

## R0–R5 — Personal Exposure / Action Level

表示对本人、家庭、企业或基地的实际行动等级。

- R0 Normal
- R1 Watch
- R2 Prepare
- R3 Alert
- R4 Emergency
- R5 Survival

Global Stage 不自动等于 Personal R-Level。

## G0–G4 — Governance Integrity

- G0 正常运行
- G1 局部失灵
- G2 严重受损
- G3 区域治理中断
- G4 国家级治理崩溃/大范围制度执行失效

政府信息是证据源之一；治理完整度本身也是监控变量。
