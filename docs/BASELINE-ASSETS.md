# Capability Baseline — Public Template

> 本公开仓库只保存能力模型与审计结构，不保存可定位到具体个人、家庭、企业或基地的敏感资产清单、容量、位置、路线、库存、联系方式或安防部署细节。

## Capability domains

实际基线应在私有数据层维护，并映射到以下能力域：

- Cash Flow / Liquidity
- Real Estate & Asset Disposition
- Industrial Space / Buildings / Land
- Energy / Solar / Storage
- Water / Well / Purification / Storage
- Food Resilience
- Mobility / Vehicles
- Physical AI / Defensive Sensing / Inspection
- Communications / Offline Network
- Medical / First Aid
- Sanitation
- Tools / Repair / Spares
- Data / Documents / Offline Knowledge
- People / Skills / Trusted Network

## Audit rule

拥有 ≠ 可用；可用 ≠ 可持续；可持续 ≠ 自给。

每项能力至少审计：
- 当前可用性；
- 外部依赖；
- 单点故障；
- 转换时间；
- 可持续时间；
- 维护与补给需求；
- 失效后的降级路径；
- 对 Personal R-Level 的实际影响。

## Public/private boundary

公开仓库只记录 schema、评分规则、Playbook 模板和脱敏示例。
真实资产数量、财务数据、精确位置、通信配置、能源/水务容量、人员与安防细节不得提交到 public `main`。
