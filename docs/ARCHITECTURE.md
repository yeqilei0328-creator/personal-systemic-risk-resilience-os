# System Architecture — Draft 0.2

## 1. System objective

本系统不是“末日预测器”，而是 Personal Systemic Risk & Resilience OS：用精准情报触达全球变化，识别风险耦合、推演场景、映射个人暴露，并把宏观变化翻译成行动。

## 2. Three engines

### 2.1 World Intelligence Engine

职责：事件发现、去重、多源验证、P0/P1/P2 优先级、事实/预测/相关性/因果区分、Physical AI Radar 兼容输入。

关键门槛：只有事件改变以下至少一项才进入高优先级输出：
- 一级风险变量状态；
- 一条系统传导边；
- Coupling Density；
- Scenario 概率/影响/速度；
- Lead Time；
- Personal Exposure；
- Action Playbook。

### 2.2 Systemic Risk Engine

四类一级变量：
- A Geopolitical Competition：战争、联盟、制裁、动员、贸易冲突、国家竞争。
- B Resource & Climate Constraints：能源、粮食、水、极端天气、自然灾害。
- C Debt & Financial Cycle：财政、主权债务、利率、房地产、地方债、银行、资本流动。
- D Technology & Capital Cycle：AI CapEx、估值、融资、生产率、技术周期。

原战争、能源/粮食、财政、美债、气候、AI、全球贸易/资本体系作为 Observation Domains，不作为彼此独立的六票。

### 2.3 Preparedness Engine

职责：将风险映射为个人、家庭、企业和基地行动，维护 Readiness Gap、Preparation Window、Disposition Window、Base Autonomy Days、Dual-Use Conversion Value。

## 3. Supporting layers

- Evidence Verification
- Scenario Engine
- Exposure Engine
- Governance Integrity
- Communications & Offline Compute
- Action Playbooks
- Audit / Anti-Doom Red Team

## 4. System output contract

每次高价值预警必须回答：
1. 发生了什么？
2. 哪条传导边发生变化？
3. 可能往哪里发展？
4. 与本人/企业/基地有什么关系？
5. 还有多少时间？
6. 现在做什么？
7. 什么不要做？
8. 什么信号出现后升级/降级？
