# Personal Systemic Risk & Resilience OS

> 不是让我比别人更早恐慌，而是让我早到，根本不需要恐慌。

本项目用于持续感知全球系统性风险、识别多系统耦合与闭合反馈、映射个人/家庭/企业/基地暴露，并在准备窗口或资产处置窗口关闭前给出可执行建议。

## Mission

将“世界发生了什么”转换为：

1. 可能往哪里发展；
2. 与本人、家庭、企业、资产和基地有什么关系；
3. 还有多少 Lead Time；
4. 现在应做什么；
5. 哪些事情暂时不要做；
6. 哪些信号出现后升级；
7. 哪些准备今天不做，以后会来不及。

## Core architecture

World Intelligence → Evidence Verification → Four-Source Risk Model → Coupling Density → Closed Feedback Loop Detection → Scenario Engine → Exposure Mapping → Lead Time / Preparation Window / Disposition Window → Personal Alert Level → Preparedness Engine → Action Playbook

## Governing principles

- Independent Risk Judgment：政府、媒体、企业、国际组织和现场数据均为信息源，不设单一真理源。
- Anti-Doom Bias：每次升级必须主动寻找反证、缓冲器和替代路径。
- No Double Counting：共同原因导致的多个下游结果不得重复计票。
- Preserve Agency：系统目标是最大化生命安全、信息判断、流动性、资源冗余和选择权。
- Peace-time Efficiency, Crisis-time Redundancy：和平时期追求效率，危机时期追求冗余。
- Dual-Use First：优先建设和平时期有经济价值、危机时期可转换为韧性/生存能力的资产。
- Graceful Degradation：关键能力应允许外部电网、互联网、物流等失效时逐级降级，而不是 100%→0%。

## Public repository boundary

本仓库公开保存方法、模型、schema、审计规则与脱敏示例；真实个人/家庭/企业/基地的敏感 operational data 不进入 public `main`。详见 `docs/DATA-BOUNDARY.md`。
